Git-遠程Git倉庫

概念：託管在因特網或其他網絡中的你的項目的版本庫

作用：保存版本庫的歷史紀錄，多人協作

創建：公司自己的服務器/第三方托管平台(Gitee,Github,Gitlab)

步驟：
1.註冊第三方托管平台網站平台
2.新建倉庫得到遠程倉庫Git地址
3.本地Git倉庫添加遠程倉庫原點地址
命令：git remote add 倉庫名稱 遠程倉庫原點地址
例如：git remote add origin https://github.com/xxx/xxx.git
4.本地Git倉庫推送到遠程倉庫
命令：git push -u 倉庫名稱 本地和遠程分支名稱
例如：git push -u origin master
完整寫法：git push --set-upstream origin master
5.查看遠程倉庫原點地址
命令：git remote -v 『fetch』原始地址，『push』目標地址
6.更新遠端倉庫網址
git remote set-url origin 輸入要更新的地址
或者
git remote rm origin
git remote add origin 輸入要更新的地址
